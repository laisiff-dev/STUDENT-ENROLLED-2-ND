📐 報到率預測模型公式（修正線性加權報到率趨勢模型 — 以報到率 % 建模）
變數定義: 各系第 t 年報到率 R(t) = (實際報到人數 Y_t ÷ 二階甄試/名額基數 B_t) × 100%
訓練集: 111–113年報到率 (t=1,2,3) → OLS線性回歸 R_lin(t) = a_R + b_R × t
加權報到率預測: R̂(t) = clamp( α×(a_R + b_R×t_target) + β×μ_R , 0%, 100% )　[α=0.55, β=0.45]
114年驗證: MAPE_R = Σ |R_實際(114) - R̂_預測(114)| / R_實際(114) / n × 100%
115年回測: δ_R = (R_實際(115) - R̂_預測(115)) / R̂_預測(115) × 100%（各系平均系統偏差）
116報到率推估: R̂₁₁₆ = clamp( R̂_5yr_model × (1 + δ_R / 2) , 0%, 100% )　← 半程誤差修正策略

六大分層招生策略建議
策略一：精準深耕高轉換生源並開發同類校
針對中山工商(25.3%)、小港高中(28.8%)、樹德家商(33.9%)、林園高中(27.3%)固本，並複製開發鳳山、瑞祥、仁武高中及鳳山商工、岡山農工、台南高工。
策略二：申請報到率鞏固（115年44.9%高點）
二階正取24hr關懷電話機制、放榜3日辦「學系歡迎日」，降低正取生「報到後放棄」流向競校比率。
策略三：整體學院資源共享與系所品牌差異化
整合附設醫院、OSCE、精準醫檢、ESG環安衛檢測與AI數位實驗室四大院級資源池，並清晰區隔院內各系國考證照與就業出口。
策略四：低報到率系所緊急干預
針對甄選護理、休遊、物治等報到率偏低系所，強化面試關懷、備取快速遞補與跨區交通住宿補貼。
策略五：跨區同類醫護與家政職校拓源
以中部巨人高中模式拓展彰化達德商工、大成商工，以高屏樹德/中山模式拓展台南曾文家商、光華高中與嘉義東吳高職。
策略六：IR報到率模型驅動名額動態配置
以各系二階報到率(%)取代人數外推，每年依據各系推估報到率動態調整甄選與申請名額配比。
